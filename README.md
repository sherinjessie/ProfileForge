# 🪪 ProfileForge

A simple, sleek profile card generator — type a name, upload a photo, write a bio, and watch your card come alive instantly.

---

## ✨ Features

- 🌙 Elegant dark-themed modern interface
- ⚡ Instant, real-time live preview
- 📸 Upload a photo directly from your device
- 🧼 Clean, intuitive, and user-friendly layout
- 💻 Built entirely with vanilla HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🎯 Purpose

This project was developed to strengthen my front-end development skills by building a fully functional profile card generator using core web technologies without relying on external libraries or frameworks.

---

## 🌟 Future Improvements

- Live preview as you type (before submitting)
- Save profile with localStorage
- Download card as an image
- Reset / clear button
- Multiple card themes to choose from
